Glosario Tecnico:

  • Archivo: Los archivos son datos almacenados en la computadora.
  • Acumuladores: Es un espacio de memoria que permite almacenar la suma de otras variables.
  • Archivo .bat: El archivo .bat ejecuta comandos de forma automática en tu computadora.
  • Algoritmo: Es una secuencia de instrucciones que permiten resolver o ejecutar una tarea específica.
  • Bloque: Son piezas que representan acciones, condiciones o datos y se conectan entre sí.
  • Bucle: Es un comando que ejecuta repetidamente un bloque de código siempre y cuando se cumpla una condición.
  • Carpeta: Es un espacio de memoria donde se guardan y ordenan los datos.
  • Constante: Es un espacio de memoria que tiene el mismo valor en toda la ejecución del programa.
  • Contadores: Es un espacio de memoria que permite llevar el seguimiento del número de veces que se ejecuta un bucle o una instrucción.
  • Control de versiones: Permite registrar modificaciones, volver a estados anteriores y trabajar en ramas paralelas.
  • Comando: Un comando es una instrucción que se le da a un sistema operativo o un programa para realizar una tarea específica.
  • Commit: Cambios registrados en el historial de git. Anotaciones que dejan los desarrolladores al cambiar o arreglar algo.
  • Copy: Comando para copiar datos.
  • CMD: Es una herramienta de Windows que te permite interactuar con el sistema operativo usando comandos.
  • Condicional: Es un comando que permite el manejo de una decisión.
  • CSS: Son las siglas de un lenguaje que permiten la personalización visual de páginas web.
  • Dev: Rama de master en la cual se trabajan las actualizaciones y cambios al proyecto.
  • Diagrama de flujo: es un algoritmo pero representado gráficamente.
  • Echo: Comando que escribe un texto en la pantalla.
  • Extensión: Son los últimos caracteres después del punto de un archivo.
  • Etiquetas: Las etiquetas son componentes básicos que se usan para crear la estructura y contenido de una página web.
  • Else: En programación es una estructura de control condicional que define un bloque de código alternativo para que se ejecute solo si la condición de un if previo resulta falsa.
  • Evento: Un evento es una señal o un aviso que emite el sistema o la aplicación cuando ocurre algo importante.
  • For: Es una estructura de control en programación que permite repetir un bloque de código un número determinado de veces.
  • Función: Una función en programación es un bloque de código reutilizable que realiza una tarea específica y puede recibir datos de entrada y devolver un resultado.
  • Fork: Un fork es un proyecto que se realiza a partir de uno ya creado, es decir, utiliza la base del proyecto anterior para crear uno nuevo.
  • getElementByld(): Es una función de JavaScript que permite buscar y seleccionar un elemento específico de un documento HTML a través del valor de su atributo id.
  • Google Drive: Es un servicio de google que permite guardar y compartir archivos en la nube.
  • Git: Es un sistema de control de versiones distribuido, diseñado para registrar y administrar los cambios que se realizan en los archivos de un proyecto.
  • Git clone: Utilizado para clonar un repositorio existente.
  • github: Es una plataforma en la nube que permite a los desarrolladores almacenar, compartir y gestionar su código fuente utilizando el sistema de control de versiones Git.
  • h1: Presenta el encabezado más importante en HTML y h6 el menos importante.
  • Header: Representa un grupo de ayudas introductorias o de navegación.
  • html: Html es un lenguaje marcado que permite la creación de páginas web.
  • ide: Es una aplicación de software que permite programar en varios lenguajes en una misma interfaz.
  • Integridad de datos: Git agrega un check, son una suma de comprobaciones a cada uno de los archivos y de los commit, de tal manera que hay una seguridad total.
  • Javascript: Javascript es un lenguaje de programación que hace las páginas web más dinámicas e interactivas.
  • Master: Así se le le denomina a la rama principal del proyecto, la cual no se puede modificar directamente.
  • Mkdir: Comando para crear una nueva carpeta.
  • Nube: La nube es un espacio de almacenamiento en línea donde podes guardar tus archivos y aplicaciones.
  • PSeInt: Es una aplicación que usa lenguajes de programación y diagramas de flujo para enseñar conceptos básicos de algoritmos.
  • Ramas: Bifurcaciones del proyecto original que no comprometen a la rama principal.
  • Repositores: Almacenan los archivos de un proyecto y todo su historial de cambios.
  • Script: Es un conjunto de comandos para realizar tareas en un lenguaje de programación automáticamente.
  • Scratch: Es un programa básico para principiantes que enseña a programar con bloques.
  • Terminal: Se refiere a la interfaz de la línea de comandos que proporciona acceso a las funciones y comandos en git.
  • Trabajo colaborativo: Grupo de personas trabajando en equipo para lograr ciertos objetivos.
  • Variable: Espacio de memoria que puede cambiar su valor mientras se ejecuta el programa.
  • Visual studio code: Es un editor de código fuente potente,ligero y gratuito.
